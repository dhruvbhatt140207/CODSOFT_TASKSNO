# CodSoft Python Programming Internship

This repository contains the three Python projects completed as part of my CodSoft Python Programming Internship.

## Task 1: To-Do List
A command-line application to manage daily tasks.

**Features:**
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using JSON

## Task 2: Calculator
A basic command-line calculator.

**Features:**
- Addition
- Subtraction
- Multiplication
- Division
- Handles invalid inputs and division by zero

## Task 3: Password Generator
A Python application that generates random passwords.

**Features:**
- Custom password length
- Lowercase and uppercase letters
- Numbers and special characters
- Option to generate another password

## Technologies Used
- Python
- JSON
- VS Code / GitHub Codespaces
